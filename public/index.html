Commons Ingest

Quarantine intake for the Browser Bridge Pattern Commons. Accepts anonymized Class C structural patterns only — never page content, values, or non-public origin structure (INV-6). Promotion and serving are Release 2.

POST /api/contributions
Accept one signed Class C record into quarantine.

POST /api/purge
{ installId } — retroactively purge an install's quarantined records.

/api/health reports storage configuration state.
